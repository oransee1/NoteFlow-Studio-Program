# NoteFlow Studio (악보 싱크 및 맵핑 오버레이 툴)

PDF 악보와 MusicXML 데이터를 시각적으로 오버레이하고, 마디 및 음표 위치를 자동 정렬하거나 수동으로 편집하여 정확하게 맵핑할 수 있는 데스크톱 애플리케이션입니다.

## 주요 기능
- **PDF 악보 렌더링 & 고화질 줌/패닝**: PyMuPDF 기반 고해상도 벡터 렌더링
- **MusicXML 파싱 & 구조 분석**: 마디(Measure) 및 음표(Note) 데이터 추출 및 시각화
- **자동 오버레이 정렬**: OpenCV 이미지 처리를 통한 오선보(Staff) 검출 및 악보 싱크 매핑
- **인터랙티브 캔버스 편집**:
  - 마디/음표 바운딩 박스 드래그 앤 드롭 및 리사이징
  - 스마트 마그네틱 스냅 (보표/오선 높이 자동 보정)
  - 다중 선택, 그룹 이동, 삭제, 키보드 이동
  - 실행 취소 / 다시 실행 (Undo/Redo)
- **MusicXML 내보내기/저장**: 위치 및 레이아웃 좌표 메타데이터가 반영된 MusicXML 저장

## 설치 및 실행 방법

### 요구 사항
- Python 3.10 이상

### 패키지 설치
`ash
pip install -r requirements.txt
`

### 실행
`ash
python main.py
`
또는 un.bat 파일을 더블 클릭하여 실행할 수 있습니다.
